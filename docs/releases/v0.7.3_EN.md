# OpenFicM 0.7.3

[简体中文](v0.7.3.md)

> Translation note: this is an English translation of an upstream OpenFicM release note; see v0.7.1_EN.md for how this repository relates to upstream.

## Reliability fixes

- A 1M-context model no longer needs the maximum output token setting to be filled in as 1000000; oversized historical configurations fall back to a safe default at the request layer.
- 429 no longer triggers automatic repeat requests, so the assistant, distillation and sub-agents cannot amplify rate limiting; after a failure you can use the retry in the UI.
- The assistant only shows models that still belong to a valid provider, and cleans up sessions and default model references left behind after a provider is deleted.
- When a sub-agent or a character/world-book consistency check fails, a warning is logged and the main agent result is still returned, instead of declaring the whole task failed.
- Tool results for large chapters, characters, world book and style guides are now bounded, reducing tasks left unfinished by ordinary models because the context got too large.

## Style distillation

- After each batch is analysed successfully a local checkpoint is saved, so after a 429, a network interruption or a failed summary, clicking again continues from the completed batches.
- It still uses at most 24 chapter samples, 6 passages per batch and at most 4 batch analyses plus 1 summary request, and never uploads the whole novel.
