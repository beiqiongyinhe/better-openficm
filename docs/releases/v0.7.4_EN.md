# OpenFicM 0.7.4

[简体中文](v0.7.4.md)

> Translation note: this is an English translation of an upstream OpenFicM release note; see v0.7.1_EN.md for how this repository relates to upstream.

## Agent collaboration and rate limiting fixes

This version tackles the problem that "the assistant is either interrupted by 429 or reports that this round's character or world-book checks were not all completed", by aligning the mobile Agent's request scheduling with upstream OpenFic's desktop client.

- Forced delegation at runtime was removed. The desktop only suggests in the prompt that specialised sub-agents should be called for different areas of work, while mobile had turned this into a hard requirement: when the main agent did not delegate on its own, the runtime would first append a reminder request, then automatically add a full sub-agent loop and finally one more integration round. An ordinary continuation was therefore amplified into double the requests. Whether to delegate is now entirely up to the model's judgement of the task.
- A whole-task model request budget was added. The main agent and all of its sub-agents share a maximum of 24 model requests per conversation; beyond that an explicit error is raised suggesting the request be split up, and a single message can no longer exhaust a relay station's per-minute request quota.
- The status display of consistency checks was corrected. Previously the UI wrote "character and world book checked and the changes confirmed in sync" regardless of whether they had actually been checked. Now it only says so when the character and world book tools were really called; otherwise it honestly reports "no character or world-book changes were found that need syncing".
- Server-overload errors (500, 502, 503, 504, 408) now retry at most 2 times instead of 3. 429 is still reported immediately with no automatic retry, and the manual retry entry point stays in the UI.
- Dead collaboration branches were removed: the unreachable "complex task did not complete specialised sub-agent collaboration" error, the fallback logic that automatically added delegation, and the sub-agent consistency status merge that no longer had any effect.

## Compatibility

- Uses the same release signing certificate as 0.7.0 onwards and can be installed as a direct upgrade.
- applicationId `com.openfic.mobile`, versionCode 11, minSdk 28, arm64-v8a only.
- Local works, chapters, characters, world book, sessions and style versions are unaffected.
