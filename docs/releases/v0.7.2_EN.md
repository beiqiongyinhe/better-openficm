# OpenFicM 0.7.2

[简体中文](v0.7.2.md)

> Translation note: this is an English translation of an upstream OpenFicM release note; see v0.7.1_EN.md for how this repository relates to upstream.

## Fixes in this version

- Style distillation no longer merges large sample blocks into a single request: up to 24 passages are drawn from the chapter distribution of the whole book, analysed in batches of 6 and finally summarised into a style guide.
- Style distillation requests compress the Lorn methodology context and automatically back off and retry on temporary errors such as 429, 408 and 5xx.
- The style book detail page shows distillation progress; failure messages are visible inside the bottom sheet and can be retried directly.
- Fixed the thought signature round-trip, empty tool calls and tool-result message compatibility for OpenAI-compatible Gemini tool calls.
- Gemini schema conversion now fills in the type of parameters that lack one, so that functionDeclaration is not rejected by the provider.
- The assistant keeps the raw 400/429 response while also showing an actionable error summary.

## Scope of use

- Style analysis does not upload the whole reference book; only up to 24 distributed chapter passages and the batch summaries are sent.
- A working model provider and model still have to be configured in the app; this version does not change local data or the release signing certificate.
- This version is first verified as a locally signed test build and does not automatically create a GitHub Release.
